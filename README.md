# Plantengids Tuin

Oefen- en opzoekgids voor tuinplanten: foto's, Latijnse namen, flashcards en een oefenmodus.

## Online zetten met GitHub Pages
1. Maak een nieuwe repository op GitHub en upload de inhoud van deze map (`index.html` en de map `photos`) in de hoofdmap.
2. Ga naar Settings > Pages. Kies bij "Source" voor "Deploy from a branch", branch `main`, map `/ (root)`, en klik op Save.
3. Na een minuut staat de site op `https://JOUWNAAM.github.io/REPONAAM/`.

Favorieten en "ken ik" worden per apparaat bewaard in de browser (niet gedeeld tussen apparaten).
